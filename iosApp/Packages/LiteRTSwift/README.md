# LiteRT TensorFlow Lite Swift API

This package contains the Apache-2.0 TensorFlow Lite Swift wrapper sources from
Google AI Edge LiteRT v2.3.0. The matching `TensorFlowLiteC.xcframework` is
downloaded from the official LiteRT v2.3.0 release and verified by SwiftPM using
the checksum in `Package.swift`.

Only the `TensorFlowLite` API used by the keyboard extension is included. The
upstream Swift source files retain their original copyright and license notices.
